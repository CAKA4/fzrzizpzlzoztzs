Find trees

—
Every condition has to be true. The search covers what the Showing filter is set to and nothing else, so another project cannot be edited by accident.

Update from an edited file

—
Nothing is created and nothing is deleted. Trees already here are corrected from the file; rows that match no tree are reported and ignored; trees the file says nothing about are left as they are.
Only trees that are showing can be matched, so another project cannot be written to by accident.
A blank cell leaves the tree's value alone — it never clears it. Tree ID, project and the photo columns are never written.
The change goes on the undo stack and syncs to the Sheet — the same rows, changed, not new ones.

Selected trees

—
A tree in no parcel is in the road allowance, so it is Public; a tree inside one is on private land, so it is Private. Shared ownership is never guessed — a boundary tree is a judgement about a stem straddling a line, and a parcel fabric is not accurate enough to make a claim about somebody's property. Trees with no position, or with no parcel layer to test against, are left alone.
Subject property and adjacent property are both private land, so both become Private; road allowance becomes Public; shared / boundary becomes Shared ownership. Only trees still carrying an old value are touched, it goes on the undo stack, and you can change any of them afterwards.
They go to the Deleted tab of the Sheet, which is the way back. This is not on the undo stack.
